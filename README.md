# Credit Card Transaction Analysis Dashboard

Business intelligence dashboard built using **Power BI** to analyze credit card transaction patterns, customer spending behavior, and revenue insights.

## Overview
This project analyzes credit card transaction data by integrating CSV datasets into **SQL Server** and visualizing key insights through an interactive **Power BI dashboard**. It helps identify spending trends, customer behavior patterns, and overall financial performance.

## Key Features

* Interactive KPI dashboard for revenue, transaction amount, interest, and transaction count
* Quarterly revenue and transaction trend analysis
* Customer segmentation by education, occupation, and card category
* Revenue analysis by expenditure type and payment method
* Dynamic filtering for detailed business insights

## Tools Used

* Power BI
* SQL Server
* CSV Dataset
* DAX

## Insights Generated
The dashboard highlights:

* Revenue distribution across card categories
* Customer spending behavior trends
* Transaction performance across quarters
* Payment method usage analysis
